## ♟️ 游戏简介

> 这里每天都有无聊的人在进行着欢乐的对话。
>
>—『学生会的一存』碧阳学园学生会议事录１，葵关南，2008

　　完全出于个人兴趣，在闲时写给自己玩儿的galgame。

　　各种地方都非常简陋，但作为我的第一个游戏，我非常喜欢它，希望你也能喜欢上它（估计很难）。

### ❗ 避雷

- GUI苦手，几乎没动。
- 无配音无立绘无CG无分支。
- 音乐和美术素材均来自网络。
- 仅支持 1920x1080 原生分辨率。
- 背景图为实地拍摄+ppt后期处理。
- 剧本内容来自[我的博客](https://beanbag-harry.netlify.app/)，所以一点也不像galgame剧本，是充满了宅味的女性不友好向游戏（笑）。

### ⭕ 重复造的一点轮子

- 章节选择。
- 音乐鉴赏（没有CG当然做不了CG鉴赏咯）。
- 模仿Infinity系列和科学ADV系列Tips List做的词典功能。
- 修改Ren'py自带的反人类按键映射。e.g.滚轮上滑就该是打开对话历史＞＜。
